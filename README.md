# Tic-Tac-Toe Game (Python)

## Overview

This project is a Python implementation of the classic Tic-Tac-Toe game, developed in Google Colab to demonstrate fundamental programming skills and problem-solving abilities.

## Features

* Interactive two-player gameplay
* Win and draw detection
* Input validation
* Restart game functionality
* Clear and organized code

## Technologies Used

* Python 3
* Google Colab

## Skills Demonstrated

* Python programming
* Functions and modular programming
* Conditional statements and loops
* Game logic implementation
* User input handling
* Debugging and problem-solving

## How to Run

1. Download or clone this repository.
2. Open the notebook (`.ipynb`) in Google Colab or Jupyter Notebook.
3. Run all cells to start the game.
